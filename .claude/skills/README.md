# Agent skills

Copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `a496f55` (MIT, see `LICENSE-mattpocock-skills`).

| Skill | Use |
|---|---|
| `improve-codebase-architecture` | Find deepening opportunities, report them, then grill through one |
| `tdd` | Build features or fix bugs test-first (red → green) |
| `handoff` | Compact the conversation into a handoff doc for a fresh session |
| `triage` | Move GitHub issues through triage states and write agent briefs |
| `codebase-design`, `grilling`, `domain-modeling` | Used by the skills above |
| `setup-matt-pocock-skills` | One-time repo setup (issue tracker, triage labels, domain docs); run before `triage` |

Not copied: `code-review` (would shadow Claude Code's built-in skill of the same name).
