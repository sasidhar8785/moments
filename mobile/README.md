# Moments app (iPhone, iPad, Android)

One React Native (Expo) codebase for iOS and Android. Film a scene with a stand-in showing where
the character will be, set where they go and what they do, and your computer generates the
moment (see `../server`).

## Put it on your iPad (Mac with Xcode)

Once:

1. Install **Xcode** from the Mac App Store and open it once. In **Xcode → Settings → Accounts**,
   add your Apple ID (a free one works).
2. Install the tools: `brew install node cocoapods` (Homebrew: https://brew.sh).
3. Get the code and build the iOS project:
   ```bash
   git clone https://github.com/sasidhar8785/moments
   cd moments/mobile
   npm ci
   npx expo prebuild --platform ios
   open ios/Moments.xcworkspace
   ```
4. In Xcode: click **Moments** in the left sidebar → **Signing & Capabilities** → **Team**: your Apple ID.
5. **Product → Scheme → Edit Scheme… → Run → Build Configuration: Release** (the app then runs
   on its own, without a development server).
6. Connect the iPad with a cable, unlock it, tap **Trust**, pick it in the device menu at the top,
   and press **▶ Run**.
7. First time on the iPad: **Settings → Privacy & Security → Developer Mode → On** (restart), and
   **Settings → General → VPN & Device Management →** your Apple ID **→ Trust**. Press Run again.

With a free Apple ID the app stops opening after 7 days; press Run again to reinstall.

Then start the server on the Mac (`../server/README.md`), open Moments on the iPad and enter the
Mac's address.

## Android

Every push to `main` builds an installable APK: GitHub → **Actions** → latest **CI** run →
**Artifacts → moments-android-apk**. Unzip it and install `app-release.apk` on the phone
(allow installing from unknown sources when asked).

## Develop

```bash
npm ci
npx tsc --noEmit     # typecheck
npm test             # unit tests (placement maths)
npx expo lint
npx expo run:ios     # or run:android: dev build with live reload
```

Native folders (`ios/`, `android/`) are generated by `expo prebuild` from `app.json`; don't edit
or commit them.

| Screen | File |
|---|---|
| Home: server status, characters, your moments | `src/app/index.tsx` |
| Server address | `src/app/settings.tsx` |
| Film with a stand-in | `src/app/capture.tsx` |
| Place and direct | `src/app/review.tsx` |
| Progress and result (play, save, share) | `src/app/job/[id].tsx` |
